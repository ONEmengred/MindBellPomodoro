# 番茄钟任务与提醒设置

## 行为

- 当前任务名随番茄会话快照保存，应用重新打开、暂停恢复、自动进入下一阶段及手动开始下一阶段时保留。
- 专注自然结束或提前停止时，任务名写入对应历史记录，并在番茄记录列表显示。修改当前任务不会更改已经写入的记录；停止后保留任务名，方便继续同一任务，用户可清空或修改。
- 旧版快照没有任务名字段时按空字符串加载，不需要数据库迁移。
- 番茄设置增加铃声、0–100% 音量与阶段通知开关，保留震动设置。设置修改通过 DataStore 原子更新，防止连续操作覆盖其他字段。
- 阶段通知开关仅控制阶段切换提醒，前台服务的计时通知继续保留；铃声、震动各自独立。迟到超过引擎宽限期的阶段切换只更新状态和记账，不补发提醒。
- 提醒通知频道本身不触发声音或震动，避免绕过震动开关或重复震动；震动由计时事件统一处理。升级使用新的 `timer_alert_v3` 频道，系统对旧频道的自定义设置不会迁移。

## 备份保护

关闭应用系统备份，并对 Android 12+ 云备份和设备迁移明确排除所有备份域。任务名、历史、设置和运行快照只保留在本机应用存储；卸载、清除数据或换机时，不通过系统备份恢复。Android 11 及更早版本也提供显式排除规则。

精确闹钟权限按版本声明：Android 12/12L 使用 `SCHEDULE_EXACT_ALARM`（maxSdkVersion=32），Android 13+ 使用计时应用的 `USE_EXACT_ALARM`。
